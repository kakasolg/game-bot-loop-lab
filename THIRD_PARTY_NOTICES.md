## 2. Repository Artifacts with Upstream Dependencies

- **[`phase1_weights.npz`](phase1_weights.npz):** Pure-NumPy MLP weight arrays pre-trained via behavioral cloning on observation/action pairs generated by running `minigrid==3.2.0`'s `BabyAIBot` in `BabyAI-GoToLocal-v0`. No MiniGrid source code is copied into the file.
- **[`demo/seed3_baseline_vs_wrapper.gif`](demo/seed3_baseline_vs_wrapper.gif) & [`demo/seed3_keyframes.png`](demo/seed3_keyframes.png):** Contain `BabyAI-GoToLocal-v0` grid frames produced by `minigrid==3.2.0` (`render_mode="rgb_array"`) and labels rendered via `pygame-ce==2.5.8` system monospace font support.
- **External demo link (`README.md`):** Links to the separate externally hosted itch.io page (`https://mokaflow.itch.io/babyai-laya-an-ai-in-the-room`); no Godot/Laya assets or source code are included in this repository, and that page is governed separately.
